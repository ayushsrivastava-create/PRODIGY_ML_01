# PRODIGY_ML_01 — House Price Prediction

## 📌 Objective
Build a Machine Learning model using Linear Regression to predict house prices based on area, number of bedrooms, and number of bathrooms.

## 📊 Dataset
- Dataset: Housing Prices Dataset
- Total records: 545
- Total columns: 13
- Target variable: `price`
- Input features: `area`, `bedrooms`, `bathrooms`

## 🛠️ Technologies Used
- Python
- Pandas
- Matplotlib
- Scikit-learn
- Google Colab

## 🤖 Algorithm
Linear Regression

## 📈 Model Evaluation
| Metric | Result |
|---|---:|
| MAE | 1,265,275.67 |
| RMSE | 1,658,324.60 |
| R² Score | 0.4559 |

## 🏠 Example Prediction
For a house with:
- Area: 3000
- Bedrooms: 3
- Bathrooms: 2

Predicted price: **5,021,117.36** (in dataset price units).

## ✅ Conclusion
This project demonstrates how Linear Regression can be used to estimate house prices. Model performance may be improved by using additional relevant features and comparing other regression algorithms.
